# Drift Miner

Godot 4 で作る、放置型の惑星採掘ゲーム（ローグライク要素つき）。アセットは使わず、図形とピクセルの描画だけで動きます。

Web 版：https://seoooma.github.io/drift-miner/ （`main` にマージされるたびに GitHub Actions が書き出して公開。スマホの縦持ち・横持ち、PC に対応）

## 遊び方

- 画面上部の惑星を、採掘ツールが自動で削る。砕いたマスに応じてクレジット（CR）が入る。惑星をタップすると手掘りもできる
- 画面下（横持ちでは右）のツール一覧で、クレジットを使ってツールを強化する。Lv25 ごとに威力が2倍。「購入 ×1 / ×10 / 最大」を切り替えられる
- 惑星の85%を砕くと破壊。残りの価値の半分がボーナスとして入り、強化カードを3枚から1枚選ぶ（そのランの間だけ有効）
- 5つ目の惑星は巨大惑星。制限時間内に割れないと再生するので、強化してから再挑戦する
- 「帰還」でランをリセットすると、到達した惑星に応じて研究データ（◆）が手に入る。◆でスキルを強化する（帰還しても残る）
- 進行は自動で保存され、閉じていた間も放置報酬が入る（最大2時間、スキルで延長）

| ツール | 動き |
| --- | --- |
| 採掘ドローン | 惑星のまわりを回り、表面を削る |
| 回転カッター | 地表を転がりながら周囲を切り崩す |
| 掃射レーザー | 衛星から地表をなぎ払う |
| 重力爆雷 | 一定間隔で落ちて広い範囲を砕く |
| コアランス | 中心核へまっすぐ穴を掘り進む |
| ナノスウォーム | 無数の微小機械が全面を少しずつ食べる |

ランごとに変わるもの：惑星の形・色・鉱脈（岩・鉄・銅・金・結晶・核）、引ける強化カード（レア・伝説あり）。

日本語表示のために Noto Sans JP のサブセットを同梱しています（SIL OFL、`fonts/OFL.txt`）。

## 構成

```
project.godot
scenes/main.tscn        ルートシーン（他のノードはコードで生成）
scripts/game_state.gd   Autoload。ツール・カード・スキルの定義、数値、保存と放置報酬
scripts/main.gd         進行（惑星の生成・クリア・巨大惑星の制限時間・タップ・自動強化・カメラ）
scripts/planet.gd       ピクセル惑星（マスごとの耐久と鉱石、削れる描画）
scripts/tools.gd        6種の採掘ツールの動きと描画
scripts/hud.gd          画面表示、ツール一覧、カード・スキル・帰還・放置報酬のパネル
scripts/backdrop.gd     背景の方眼と星
scripts/fx.gd           破片と数値ポップの演出
```
