# Drift Miner

Godot 4 で作る、プロシージャル生成の宇宙採掘ローグライク（プロトタイプ）。

## 遊び方

Godot 4.3 以降で `project.godot` を開き、F5 で実行します。アセットは不要で、図形描画だけで動きます。

**操縦も建設も自動です。** 自機はオートパイロットで採掘・回収・探索・漂流物の回収を行い、建物は持っているキットに合わせて母船のまわりに自動で建ちます。プレイヤーが決めるのは次の3つだけです。

| 決めること | 内容 |
| --- | --- |
| 強化カード | 生産するとレベルが上がり、カード3枚（スキルで4枚）から1枚選ぶ。工場の増設・速度アップ・燃料対策など |
| 航路 | ワープの資源がそろうと、見つかったゲートから行き先を選ぶ（近い平凡なゲートか、遠い報酬大のゲートか）。もう少し探索して貯めることもできる |
| 速度・おまかせ | 右下のボタンで速度 ×1/×2/×3（PCは Space）。「おまかせ」をONにするとカードも自動で選ぶ |

## ゲームの流れ

**母艦（ランの外）**：ランで得た研究データでスキルツリーを解放する。5段階・15スキルで、前の段階のスキルが前提になる。初期資材、採掘機の量産、組立ライン、量子炉の設計図、高効率工場、カード選択肢の拡張、再抽選など。進行は保存される。

**遠征（ラン）**：
1. セクターの中心に母船（倉庫）がある。鉱石は鉄（灰）・銅（橙）・氷（水色、燃料になる）・結晶（紫）
2. 生産チェーン（工場は自動配置）
   - 製鉄炉：鉄鉱石2 → 鉄板1（2秒）
   - 伸線機：銅鉱石1 → 銅線2（2秒）
   - 組立機：鉄板1＋銅線3 → 回路1（4秒）
   - 量子炉（スキルが必要）：結晶2＋回路1 → 量子コア1（6秒）
3. 採掘機は足りない鉱石の小惑星に自動で建ち、ドローンハブが母船へ運ぶ。ハブが届かない採掘機は自機が回収しに行く
4. 生産すると経験値がたまり、レベルアップごとに強化カードを選ぶ（毎回ランダム）
5. ワープには回路（セクター5からは量子コアも）が必要で、後半ほど急に増える。到着150秒後から宙域が不安定化し、燃料の減りが加速する
6. ワープ時に建物は畳まれ、次のセクターで自動で建て直される。ゲートごとに強化2択か4択を選ぶ
7. セクター10の最終ゲートで帰還成功。燃料切れでラン終了。どちらでも研究データが入る

ランごとに変わるもの：セクターの地形と種類、ゲートの行き先、漂流物の中身（資源・キット・星図、まれに罠）、隕石、引けるカード。

## 構成

```
project.godot
scenes/main.tscn          ルートシーン（他のノードはコードで生成）
scripts/game_state.gd     Autoload。資源・建物・レシピ・強化カード・スキルツリーと保存
scripts/sector_generator.gd  シードから小惑星帯とゲート位置を生成
scripts/main.gd           進行管理、探索（霧）、自動建設、カードと航路、ワープ
scripts/player.gd         自機のオートパイロット（採掘・回収・探索・回避）
scripts/asteroid.gd       小惑星（形もシードから生成）
scripts/miner.gd          採掘機
scripts/machine.gd        工場（製鉄炉・伸線機・組立機・量子炉）
scripts/drone_hub.gd      ドローンハブと輸送ドローン
scripts/core.gd           母船（倉庫と補給圏）
scripts/warp_gate.gd      ワープゲート
scripts/hud.gd            UI、カード・航路選択、ゲームオーバー、スキルツリー
scripts/touch_controls.gd スマホ判定（表示の拡大に使う）
scripts/starfield.gd      背景、放射線域、セクター境界
scripts/derelict.gd       漂流物
scripts/meteor.gd         隕石の予告と着弾
scripts/fx.gd             破片と数値ポップの演出
```
