# Drift Miner

Godot 4 で作る、放置型の巨大惑星採掘ゲーム（ローグライク要素つき）。見た目は黒い宇宙に細いネオンの線で描く HUD 風。効果音には Kenney の CC0 素材、BGM には CC0 の楽曲を使っています（[CREDITS.md](CREDITS.md)）。

Web 版：https://seoooma.github.io/drift-miner/ （`main` にマージされるたびに GitHub Actions が書き出して公開。スマホの縦持ち・横持ち、PC に対応）

## 遊び方

- 巨大なピクセル惑星の一部を大きく映し（ブロック1つが画面幅の約1/20）、採掘機の一団が近くの鉱石や遺物を自動で選んで削る。機体どうしは狙うマスを分担し、同じマスを取り合わない。深いブロックほど硬く、砕いたときのクレジット（CR）も多い
- 主人公は母艦。機体はみな母艦から出て、母艦の真下の周りで働く。砕いた鉱石や宝箱からは光の粒が母艦へ吸い込まれる（数値は砕いた瞬間に入る）
- タップは攻撃ではなく「母艦の移動先の指定」（緑の角かっこ）。母艦はそこへ移動し、周りを掘り尽くすと自動の探索に戻る。機体は外とつながった掘り跡だけを通り、まだ掘っていない岩の内側には入らない
- 自動で動くときは、着いた場所の鉱石を少なくとも2秒は掘り、はっきりよい場所が見つかったときだけ移る。向かう先はシアンの角かっこで示し、母艦からその方向へ短い破線が伸びる。画面の外なら、画面の端に矢印と距離（マス）が出る。カメラは進む方向へ少し先回りする
- 右上の地図で惑星全体と今見ている範囲が分かる
- BGM と効果音つき。左の「音」ボタンでオン・オフを切り替えられる（設定は保存される）
- 画面下（横持ちでは右）のツール一覧で、CR を使ってツールを強化する。Lv25 ごとに威力が上がる。購入数は ×1 / ×10 / 最大
- 惑星の95%を砕くと破壊。1つの惑星はおよそ20分のボリューム。破壊すると CR・ツール・遺物はリセットされ、次の（ずっと硬い）惑星へ進む。クリア画面と右上には、前の惑星の所要時間も出る
- 進行は自動で保存され、掘った跡も残る。閉じていた間も放置報酬が入る（最大2時間、スキルで延長）

### ブロックの中身（ローグライク要素）

惑星の形・鉱脈・埋まっている物は毎回ランダム。惑星ごとに「銅の惑星」「遺跡の惑星」「火山惑星」などの特性も付く。

| ブロック | 中身 |
| --- | --- |
| 鉄・銅・金・結晶 | スキルマップに使う素材。深いほど金と結晶が増える |
| 遺物 | 岩に紛れて埋まっている。掘り当てると、その惑星の間だけ効く効果がランダムに付く |
| 宝箱 | CR と素材がまとめて手に入る |
| 爆薬岩 | 砕くと周りを巻き込んで爆発し、連鎖する |
| 硬い岩 | 耐久が高い障害物 |

### スキルマップ

素材で強化し、惑星を変えても残る。母艦を中心に5つの系統が放射状に広がり、系統のあいだも橋のノードでつながる網の目（52ノード）。習得済みのノードとつながっているノードを習得できる。ドラッグで動かし、+/- やピンチで拡大縮小する。

- 中心から内・中・外の3段に分かれ、中は惑星3、外は惑星5に着くと解放される（点線の円が境目）
- 各系統の端に、代償つきの「要石」（ひし形）が1つずつある。付けられるのは1つだけで、外すと素材は全額戻る
  - 共鳴群：ドローンの威力 ×(機数×2)、ほかのツール ×0.5
  - 重機運用：ドローン以外のツール ×5、ドローン ×0.2
  - 先行投資：惑星に着いたときの CR ×50、獲得 CR ×0.6
  - 遺物狩り：遺物と宝箱が3倍、素材 ×0.7
  - 無人航行：タップで移動できない代わりに、自動探索の範囲と移動速度 ×2
- 惑星を割るたびに1回、全スキルを外して素材を全額戻す「振り直し」ができる

- 大きなノード：ツールの解放や、威力・経済・探査・自動化の主な効果
- 小さなノード：威力 +15%、ドローン威力 +25%、強化費用 -4%、獲得 CR +10%、素材 +5%、移動速度 +25% のどれか（最大Lv3）
- 採掘力：ドローン出力・増設、共振増幅、推進器、過負荷運転
- ツール：パルスドリル → 精密レーザー → 重力爆雷 → コアランス → ナノスウォーム の解放、ツール熟練
- 経済：獲得 CR、強化費用、初期資金、放置報酬、複利
- 探査：素材の入手量、透視スキャン（遺物が見える）、遺物の勘、精錬、核の回収
- 自動化：自動探索（遠くの鉱脈へ移動）、自動強化、誘爆制御、航路選択（次の惑星を候補から選ぶ）

文字は等幅の Share Tech Mono（英数字）と M PLUS 1 Code（日本語、サブセット）を同梱しています（どちらも SIL OFL）。

## 構成

```
project.godot
scenes/main.tscn        ルートシーン（他のノードはコードで生成）
scripts/game_state.gd   Autoload。ツール・ブロック・惑星特性・遺物・スキルマップの定義、数値、保存と放置報酬
scripts/main.gd         進行（惑星の生成と復元・ブロックの報酬・クリア・タップ・自動化・カメラ）
scripts/planet.gd       巨大ピクセル惑星（マスごとの耐久と中身、爆発、削れる描画）
scripts/tools.gd        6種の採掘ツールの動きと描画
scripts/hud.gd          画面表示、ツール一覧、スキルマップ・遺物・惑星クリア・放置報酬のパネル
scripts/skill_map.gd    スキルマップの描画と操作（ドラッグ・拡大縮小・選択）
scripts/audio.gd        Autoload。BGM のループと効果音（間引き・音程のゆらぎ・オンオフ）
scripts/backdrop.gd     背景（地模様・星雲・視差のある星）
scripts/fx.gd           演出（破片・火花・発光・衝撃波・爆発アニメ・数値ポップ）
scripts/neon.gd         見た目の決まりごと（色・線・にじみ・線のアイコン）を一か所に
scripts/bracket_box.gd  角かっこ付きのボタンの枠
shaders/cells.gdshader  惑星を平らな塗りと白い階段状の輪郭線で描くシェーダー
assets/                 音（素材の出どころは CREDITS.md）
```
