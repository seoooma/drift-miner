# Drift Miner

Godot 4 で作る、プロシージャル生成の宇宙採掘ローグライク（プロトタイプ）。

## 遊び方

Godot 4.3 以降で `project.godot` を開き、F5 で実行します。アセットは不要で、図形描画だけで動きます。

| 操作 | 内容 |
| --- | --- |
| WASD | 移動（移動中は燃料消費が増える） |
| 1〜6 / 画面下のボタン | 建設モード（左クリックで設置、右クリックで取消） |
| 左クリック長押し | カーソル下の小惑星を採掘（範囲は機体周りの薄い円） |
| E | ワープゲートの近くで次のセクターへワープ |
| R | ゲームオーバー後に母艦へ |

### スマホで遊ぶ

`main` にマージされるたびに GitHub Actions が Web 版を書き出し、GitHub Pages に公開します。
URL：https://seoooma.github.io/drift-miner/ （横向き推奨）

| タッチ操作 | 内容 |
| --- | --- |
| 画面左側をドラッグ | バーチャルスティックで移動 |
| 画面右側を長押し（照準は近くの小惑星に吸い付く） | 採掘 |
| 画面下の建設ボタン → 場所をタップ | 建物を設置（同じボタンで取消） |
| 「ワープ」ボタン | ゲート付近でワープ |

日本語表示のために Noto Sans JP のサブセット（JIS第1・第2水準漢字＋かな）を同梱しています（SIL OFL、`fonts/OFL.txt`）。

## ゲームの流れ

**母艦（ランの外）**：ランで得た研究データで技術を解放する。量子炉の設計図、初期キット、ドローン増設、工場の高速化など。進行は保存される。

**遠征（ラン）**：
1. セクターの中心に母船がある。母船は倉庫で、工場は母船の青い円（補給圏）の中に建てる
2. 鉱石は鉄（灰）・銅（橙）・氷（水色、燃料になる）・結晶（紫）。手掘りか採掘機で掘る
3. 生産チェーンをつなぐ
   - 製鉄炉：鉄鉱石2 → 鉄板1（2秒）
   - 伸線機：銅鉱石1 → 銅線2（2秒）
   - 組立機：鉄板1＋銅線3 → 回路1（4秒）
   - 量子炉（要研究）：結晶2＋回路1 → 量子コア1（6秒）
4. ドローンハブを置くと、周囲の採掘機から母船へドローンが自動で運ぶ
5. ワープには回路（セクター5からは量子コアも）が必要。到着150秒後から宙域が不安定化し、燃料の減りが加速する
6. ゲートは2つ（近い平凡なゲートと、遠い報酬大のゲート）。ワープ時に建物は畳んでキットになり、次のセクターで再配置できる。強化を1つ選ぶ
7. セクター10の最終ゲートで帰還成功。燃料切れでラン終了。どちらでも研究データが入る

危険と寄り道：放射線域（燃料消費2.5倍）、隕石（予告あり、範囲内の建物が壊れる）、漂流物（資源・キット・星図、まれに罠）

## 構成

```
project.godot
scenes/main.tscn          ルートシーン（他のノードはコードで生成）
scripts/game_state.gd     Autoload。資源・建物・レシピ・パーク・研究と保存
scripts/sector_generator.gd  シードから小惑星帯とゲート位置を生成
scripts/main.gd           進行管理、探索（霧）、採掘機の設置、ワープ
scripts/player.gd         自機の移動と採掘
scripts/asteroid.gd       小惑星（形もシードから生成）
scripts/miner.gd          採掘機
scripts/machine.gd        工場（製鉄炉・伸線機・組立機・量子炉）
scripts/drone_hub.gd      ドローンハブと輸送ドローン
scripts/core.gd           母船（倉庫と補給圏）
scripts/warp_gate.gd      ワープゲート
scripts/hud.gd            UI、パーク選択、ゲームオーバー
scripts/touch_controls.gd スマホ用タッチ操作
scripts/starfield.gd      背景、放射線域、セクター境界
scripts/derelict.gd       漂流物
scripts/meteor.gd         隕石の予告と着弾
scripts/fx.gd             破片と数値ポップの演出
```
