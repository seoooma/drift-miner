# Drift Miner

Godot 4 で作る、放置型の巨大惑星採掘ゲーム（ローグライク要素つき）。アセットは使わず、図形とピクセルの描画だけで動きます。

Web 版：https://seoooma.github.io/drift-miner/ （`main` にマージされるたびに GitHub Actions が書き出して公開。スマホの縦持ち・横持ち、PC に対応）

## 遊び方

- 画面からはみ出すほど大きなピクセル惑星を、採掘ツールが自動で削る。深いブロックほど硬く、砕いたときのクレジット（CR）も多い。タップで手掘りもできる
- 画面下（横持ちでは右）のツール一覧で、CR を使ってツールを強化する。Lv25 ごとに威力が上がる。購入数は ×1 / ×10 / 最大
- 惑星の95%を砕くと破壊。1つの惑星はおよそ20分のボリューム。破壊すると CR とツールはリセットされ、次の（ずっと硬い）惑星へ進む
- 進行は自動で保存され、掘った跡も残る。閉じていた間も放置報酬が入る（最大2時間、スキルで延長）

### ブロックの中身（ローグライク要素）

惑星の形・鉱脈・埋まっている物は毎回ランダム。惑星ごとに「銅の惑星」「遺跡の惑星」「火山惑星」などの特性も付く。

| ブロック | 中身 |
| --- | --- |
| 鉄・銅・金・結晶 | スキルツリーに使う素材。深いほど金と結晶が増える |
| 遺物 | 岩に紛れて埋まっている。掘り当てると、その惑星の間だけ効く効果がランダムに付く |
| 宝箱 | CR と素材がまとめて手に入る |
| 爆薬岩 | 砕くと周りを巻き込んで爆発し、連鎖する |
| 硬い岩 | 耐久が高い障害物 |

### スキルツリー

素材で強化し、惑星を変えても残る。5系統・26ノードで、親ノードを習得すると先へ進める。

- 採掘力：ドローン出力・増設、手掘り、共振増幅、過負荷運転
- ツール：回転カッター → 掃射レーザー → 重力爆雷 → コアランス → ナノスウォーム の解放、ツール熟練
- 経済：獲得 CR、強化費用、初期資金、放置報酬、複利
- 探査：素材の入手量、透視スキャン（遺物が見える）、遺物の勘、精錬、核の回収
- 自動化：自動タップ、自動強化、誘爆制御、航路選択（次の惑星を候補から選ぶ）

日本語表示のために Noto Sans JP のサブセットを同梱しています（SIL OFL、`fonts/OFL.txt`）。

## 構成

```
project.godot
scenes/main.tscn        ルートシーン（他のノードはコードで生成）
scripts/game_state.gd   Autoload。ツール・ブロック・惑星特性・遺物・スキルツリーの定義、数値、保存と放置報酬
scripts/main.gd         進行（惑星の生成と復元・ブロックの報酬・クリア・タップ・自動化・カメラ）
scripts/planet.gd       巨大ピクセル惑星（マスごとの耐久と中身、爆発、削れる描画）
scripts/tools.gd        6種の採掘ツールの動きと描画
scripts/hud.gd          画面表示、ツール一覧、スキルツリー・遺物・惑星クリア・放置報酬のパネル
scripts/backdrop.gd     背景の方眼と星
scripts/fx.gd           破片と数値ポップの演出
```
